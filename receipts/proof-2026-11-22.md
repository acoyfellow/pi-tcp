# Proof: 2026-11-22

Claim: One Pi Durable session takes turns from raw TCP and from a browser at the same time; each side sees the other's turns; a reconnect on either side loses no turns.

Result: **proven** in 3.2s against http://localhost:8791 and 127.0.0.1:7000. Session `proof-mwrvxz0q`.

| Check | Result | Detail |
|---|---|---|
| browser socket with a bad token is refused | pass | handshake rejected |
| both transports join one session | pass | 1 tcp, 1 web |
| browser sees a turn asked over TCP | pass | entry #7 via tcp |
| browser sees the reply to the TCP turn | pass | "ack tcp" |
| TCP sees a turn asked from the browser | pass | entry #12 via web |
| TCP sees the reply to the browser turn | pass | "ack web" |
| TCP reconnect replays the turn it missed | pass | 2 entries after #15 |
| browser reconnect replays the turn it missed | pass | 2 entries after #19 |
| history is ordered with no duplicates | pass | 8 entries |
| history holds all four user turns | pass | tcp,web,web,tcp |

Reproduce: `npm run dev` in one terminal, `npm run proof` in another.
